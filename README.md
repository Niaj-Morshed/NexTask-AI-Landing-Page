🚀 NexTask – AI-Powered SaaS Landing Page with Cinematic UI & Smooth Animations
------------------------------------------------------------------------------------
Live Demo: [https://niaj-morshed.github.io/Paws-Pet-Shop/](https://niaj-morshed.github.io/NexTask-AI-Landing-Page/)


🚀 Overview:
-------------
NexTask is a modern, high-performance landing page designed for AI-driven task 
automation platforms.Built with a focus on immersive UI/UX, it features a 
cinematic design, smooth scroll animations, and a fully responsive layout.


✨ Key Features:
-----------------
1. 🤖 Futuristic AI Interface
    * Modern dark-themed aesthetic specifically for SaaS products
    * Glassmorphism effects on navigation and cards
    * High-quality visual assets and gradient overlays

2. 🎭 Cinematic Animations (ScrollReveal.js)
    * Elements reveal smoothly as the user scrolls
    * Staggered animation for feature cards and pricing tables
    * Zero-lag, high-performance interaction design

3. ⚡ Interactive Feature Showcase
    * Hover-active feature cards with glow effects
    * Interactive UI components to explain AI workflows
    * Visual storytelling through structured sections

4. 🌙 Theme Consistency
    * Optimized for dark-mode as the primary SaaS aesthetic
    * Fully styled using CSS variables for easy customization
    * Consistent branding across all sections

5. 📊 Premium Pricing Table
    * Clean, professional pricing tiers (Basic, Pro, Enterprise)
    * "Most Popular" badge with highlighted border-glow
    * Interactive "Get Started" call-to-action buttons

6. 📱 Fully Responsive Design
    * Mobile-first responsive architecture
    * Custom hamburger menu for smaller screens
    * Adaptive typography and image scaling for all devices

7. 🎨 Advanced UI/UX Details
    * Custom scrollbar styling to match the AI theme
    * Micro-interactions on buttons (bounce and scale effects)
    * Smooth internal section navigation (Smooth Scroll)



🛠️ Technologies Used:
----------------------
1. Core Stack
    * HTML5: Semantic structure for SEO and accessibility.
    * CSS3: Advanced styling using Flexbox, Grid, and Keyframe animations.
    * JavaScript: Logic for menu toggles, scroll effects, and interactivity.

2. Libraries & Tools
    * ScrollReveal.js: For the signature cinematic reveal animations.
    * Font Awesome: For professional scalable vector icons.
    * Google Fonts: Used "Poppins/Inter" for that clean tech feel.

3. Design Principles
    * Visual Hierarchy: Directing user attention to CTA buttons.
    * Performance: Optimized for fast LCP (Largest Contentful Paint).
    * Brand Identity: Consistent use of "Neon Blue" accent colors.
